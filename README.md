# ChatForum using Skipgram for Query Analysis 

## Description
Chat Forum is a hybrid communication platform that combines the structured organization of traditional discussion forums with the speed and interactivity of real-time chat. The platform provides users with an organized environment where they can participate in topic-based discussions, communicate in real time, and manage discussion threads efficiently.

## Features

The Chat Forum provides separate functionalities for **Users** and **Administrators**, allowing discussions to be organized and managed efficiently.

### User Features

- **Browse Rooms** – Users can browse different rooms available for creating and participating in discussion threads.
- **Search Threads** – Users can search for discussion threads using relevant keywords.
- **Read Thread Discussions** – Users can view and read existing discussions within threads.
- **Create Threads** – Users can create new threads for starting discussions on specific topics.
- **Message in Threads** – Users can send messages and participate in ongoing thread discussions.
- **Edit Created Threads** – Users can edit the threads they have created.
- **User Authentication** – Users must log in to the system to access thread-related functionalities.

### Admin Features

- **Add Rooms** – Administrators can create new rooms for organizing discussion threads.
- **Edit and Remove Rooms** – Administrators can modify or remove existing rooms.
- **Manage Rooms and Users** – Administrators can manage rooms and the users associated with them.
- **Manage Threads** – Administrators can add, edit, and delete any discussion thread.
- **Admin Authentication** – Administrators must log in to the system before accessing administrative functionalities.

### Main Features

- **User Authentication and Authorization**
- **Room Management**
- **Thread Creation and Management**
- **Real-Time Thread Messaging**
- **Keyword-Based Thread Search**
- **Thread Discussion Viewing**
- **User-Created Thread Editing**
- **Admin Room and User Management**
- **Admin Thread Management**
- **Organized Topic-Based Discussions**
